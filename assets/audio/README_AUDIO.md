# Аудиофайлы для озвучки

Положите готовые MP3-файлы именно в эту папку и сохраните указанные имена.

## Требования к голосу

- доброжелательный молодой женский голос;
- естественная живая речь, без театральности;
- лёгкая улыбка в голосе;
- спокойный темп;
- без шёпота, эха, реверберации и «сказочного» искажения;
- чёткая русская дикция;
- формат MP3;
- желательно mono, 44.1 kHz, 128–192 kbps;
- без длинной тишины в начале и конце.

## Обязательные файлы

### voice-welcome.mp3
Тебе пришло секретное задание! Пройди три испытания и открой приглашение.

### voice-key.mp3
Первое испытание. Найди ключ с круглым отверстием.

### voice-stars.mp3
Второе испытание. Собери шесть золотых звёзд.

### voice-chest.mp3
Третье испытание. Найди сундук рядом с замком.

### voice-final.mp3
Поздравляю! Ты открыл секретное приглашение! Ждём тебя двадцать девятого августа в двенадцать тридцать.

## Общий промпт для генератора голоса

Доброжелательный молодой женский голос для детской игры. Естественная, тёплая и спокойная речь, лёгкая улыбка в голосе. Без шёпота, без мистического или пугающего оттенка, без переигрывания, без эха и реверберации. Чёткая русская дикция. Темп немного медленнее обычного разговора.
