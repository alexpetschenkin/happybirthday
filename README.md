# Мини-квест с приглашением — версия 3

В этой версии добавлены:

- тихая оригинальная фоновая мелодия, создаваемая браузером;
- отдельные звуки кнопок, ошибки, ключа, звёзд, сундука и победы;
- голосовые подсказки на русском через встроенный синтез речи устройства;
- запуск со звуком или без звука;
- тематическая карта прогресса;
- анимированное открытие сундука;
- раскрытие приглашения как свитка;
- время начала 12:30 поверх приглашения;
- блок информации для родителей;
- копирование адреса;
- добавление события в календарь;
- подтверждение участия через системное меню «Поделиться» или копирование текста.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий.
2. Загрузите всё содержимое архива в корень репозитория.
3. Откройте Settings → Pages.
4. Выберите Deploy from a branch → main → /(root).
5. После публикации используйте персональные ссылки:

- `АДРЕС/danil.html`
- `АДРЕС/dima.html`
- `АДРЕС/artem.html`
- `АДРЕС/egor.html`
- `АДРЕС/vlada.html`

## Звук

Мобильные браузеры разрешают звук только после нажатия пользователя. Поэтому на первом экране есть кнопка «Начать со звуком». Музыка и эффекты полностью оригинальные и генерируются Web Audio API, внешние аудиофайлы не требуются.

Голосовые подсказки зависят от голосов, установленных на смартфоне. Если русской озвучки на устройстве нет, игра продолжит работать без неё.
